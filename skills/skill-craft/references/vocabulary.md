# 机器腔词表（发布场景精选，参考非清单）

数据文件，供 `craft_cli.py` 的警告级 lint 与人工审校参考。提炼自 reduce-ai-zh 的完整词表，
只保留发布文案高发类别。用法：命中不是罪，问一句——删掉它，信息量受损吗？
不受损就删，受损就落实成具体内容。机械替换会制造新的机器腔。

## 营销形容词

| 词 | 处理 |
|---|---|
| 强大 / 优秀 / 卓越 / 良好 | 删或换成可验证的表述 |
| 高效 / 轻松 / 惊人 | 删；性能主张落实成实测数字 |
| 一站式 / 全方位 / 端到端 | 删或具体化到到底覆盖哪段 |
| 赋能 / 抓手 / 深度融合 / 有机结合 | 写清楚具体做了什么、在哪结合 |

## 空泛开场

| 词句 | 处理 |
|---|---|
| 随着……的快速发展 | 换成具体现象、数据或矛盾开场 |
| 众所周知 / 不言而喻 | 删。真众所周知就不用写 |
| 值得注意的是 / 需要指出的是 | 删，直接说要说的事 |

## 万能动词框架

| 词句 | 处理 |
|---|---|
| 进行了……（分析/优化/实现） | 直接用动词：分析了、优化了 |
| 实现了……的提升 | 提升了，且给出从多少到多少 |
| 奠定了坚实的基础 / 提供了有力支撑 | 删 |

## 排比触发器

| 词句 | 处理 |
|---|---|
| 不仅……而且……更…… | 语义真递进才用；多数是平列，拆成两句 |
| 四字格连排（稳定可靠、快速响应、易于维护） | 一段最多一组，多数场合改散句 |
| 既……又……更…… | 同上 |

## 点题说教

| 词句 | 处理 |
|---|---|
| 这标志着……迈入新阶段 / 新的里程碑 | 删整句，改动列表写完就停 |
| 由此可见 / 综上所述 | Release 正文里直接删 |

## 排版指纹

| 形态 | 处理 |
|---|---|
| 标题带 emoji（🚀 快速开始、✨ 特性） | 全部去掉 |
| 自问自答标题（"为什么选择 X？"） | 删标题，让事实说话 |
